# Статическая версия сайта

Тексты, характеристики, контакты и изображения зафиксированы из опубликованной версии сайта 28 ноября 2026 года. Весь контент включён в файлы. Подключения к базе данных, авторизации и админки нет.

## Обновление существующего репозитория GitHub

1. Распакуйте архив static-update-existing-repo.zip.
2. Загрузите всё его содержимое в КОРЕНЬ вашего существующего репозитория с заменой одноимённых файлов. Сохраните структуру папки assets. Не загружайте сам ZIP и не создавайте дополнительную папку над index.html.
3. Дождитесь завершения публикации GitHub Pages и обновите сайт через Ctrl+F5.
4. Проверьте страницу и изображения. После этого можно приостановить прежний проект базы данных: этому сайту он больше не нужен.

admin.html перенаправляет на главную страницу; admin.js, admin.css, config.js и cms.js заменены пустыми заглушками. Они нужны в архиве для безопасной замены старых файлов в существующем репозитории. Рабочая страница эти файлы не подключает.

## Локальный просмотр

Откройте index.html двойным щелчком. Интернет, сервер, установка пакетов и сборка не требуются. Вкладки материалов, вопросы и ответы и мобильное меню продолжают работать.

## Изменения в будущем

- index.html: тексты, контакты, метатеги и содержимое страницы.
- product-data.js: характеристики трёх типов изделий во вкладках.
- styles.css: оформление.
- assets: локальные изображения, шрифт и документы.

Сохраните эти файлы как рабочую копию сайта. Дальнейшие изменения вносятся в файлы и загружаются на GitHub.
