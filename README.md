# Тепломатериал — одностраничный сайт

Статический лендинг по презентации Марии Хакимовны Абдуллиной, заявка СтС-530377, 2025 год. HTML, CSS и JavaScript без сборки и npm. Для админки подготовлено подключение управляемого бэкенда Supabase. Шрифт Manrope и фотографии включены в assets.

## Локальный просмотр

Распакуйте архив и откройте index.html двойным щелчком в современном браузере. Сохраняйте структуру папок: index.html, styles.css, script.js и assets должны оставаться рядом. Интернет для просмотра не нужен.

При наличии Python можно запустить из папки сайта `python -m http.server 8080` и открыть http://localhost:8080. Остановка сервера: Ctrl+C.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий на GitHub.
2. Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория: index.html должен находиться в корне, а не внутри дополнительной папки teplomaterial. Вместе с файлами загрузите папку assets. Файл .nojekyll включает публикацию без обработки Jekyll.
3. Откройте Settings → Pages → Build and deployment.
4. В Source выберите Deploy from a branch.
5. Выберите ветку main, папку / (root), затем Save.
6. Дождитесь завершения публикации. Адрес сайта появится на той же странице. Обычно он имеет вид https://USERNAME.github.io/REPOSITORY/.

Инструкция проверена по документации GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Все пути к стилям, скриптам и изображениям относительные. Сайт подходит как для проектного репозитория, так и для USERNAME.github.io. Публикация из этого чата не выполнялась.

## Что можно изменить

- index.html: тексты, контакты, разделы и метатеги.
- styles.css: цвета в :root, размеры и адаптивная вёрстка.
- product-data.js: исходные данные вкладок с характеристиками изделий.
- script.js: меню, вкладки и анимации страницы.
- assets: фотографии, шрифт и его лицензия.

«Тепломатериал» — рабочее название оформления сайта, его нет в презентации.

## Точность содержания

Сведения относятся к презентации 2025 года. Текущий статус производства, команды, документов и готовности продукции требует актуализации автором. Характеристики плит взяты из сравнительной таблицы слайда 4. Для блоков показаны только плотность и прочность со слайда 3: размерность теплопроводности там неоднозначна. Противоречащие друг другу цены из разных слайдов не опубликованы. Патенты не заявлены как полученные. Отзывы и сертификаты не выдуманы.

Контакты руководителя взяты из презентации. Ссылки электронной почты и телефона открывают соответствующие приложения; сайт ничего не отправляет самостоятельно. Публичный лендинг не содержит аналитики и форм заявок. Админка использует Supabase Auth, локальный черновик браузера и хранилище опубликованного содержимого.

После размещения замените og:image в index.html на абсолютный публичный URL изображения, например https://USERNAME.github.io/REPOSITORY/assets/products.jpg. Это необходимо для надёжного предпросмотра ссылки в социальных сетях.

Фотографии и копии титульных листов извлечены из предоставленной презентации. Шрифт Manrope распространяется по SIL Open Font License, текст лицензии в assets/FONT-LICENSE.txt.



## Обновление оформления

Добавлена инфографика с концептуальной ИИ-иллюстрацией гранулы в разрезе и схемой от сырья к изделиям. Подвал и кнопки связи удалены по запросу. Прямые контакты сохранены. Изображение assets/porous-granule.png не является микрофотографией или точной моделью. Промпт и способ генерации приведены в GENERATION.md.


## Админка

Небольшая иконка пользователя в шапке открывает admin.html. Доступны редактирование текстов, изображений, контактов и характеристик изделий, предпросмотр, импорт и экспорт JSON. Для настоящего входа и публикации выполните SUPABASE-SETUP.md. Публичные настройки подключения находятся в config.js, схема базы и RLS — в supabase/schema.sql. До подключения доступна проверка в локальном режиме через HTTP сервер.
